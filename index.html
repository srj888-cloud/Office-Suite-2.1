    💬 FEEDBACK
    1. e-Office Suite
      e-Office ല്‍ ഡ്രാഫ്റ്റുകൾ തയ്യാറാക്കുന്നതിനായിട്ടാണ് ഈ Application വികസിപ്പിച്ചിരിക്കുന്നത്.
    2. പ്രത്യേകതകൾ
      മലയാളത്തിലും ഇംഗ്ലീഷിലും ഡ്രാഫ്റ്റുകൾ തയ്യാറാക്കി Alignment തെറ്റാതെ eoffice ൽ പകർത്താം, Mail Merge, Direct Copy Paste from the uploaded excel file.
    3. Bookmark
      Web Application തുറന്ന ഉടനെ Link bookmark ചെയ്ത് സൂക്ഷിക്കുന്നത് നന്നായിരിക്കും.
    4. Browser
      ഈ Web Application പൂര്‍ണമായും പ്രവര്‍ത്തിക്കുന്നത് ഇത് തുറക്കുന്ന ബ്രൗസറിലാണ്. ഇതിന് സെര്‍വര്‍ ഇല്ല. ആയതിനാല്‍ സുരക്ഷിതമായി ഉപയോഗിക്കാം.
    5. ഓഫീസ് പ്രൊഫൈൽ തയ്യാറാക്കുക
      മുകളിലെ ⚙ Settings ലെ Office Profile ടാബില്‍ ഓഫീസ് വിവരങ്ങൾ മലയാളത്തിലും ഇംഗ്ലീഷിലും പൂരിപ്പിച്ച് Save Profile ക്ലിക്ക് ചെയ്യുക. വിലാസം പോലുള്ള ബോക്സുകളില്‍ അടുത്ത വരിയിലേക്ക് പോകാന്‍ Enter അമര്‍ത്തിയാല്‍ മതി. Save ചെയ്താല്‍ Profile Active എന്ന് കാണിക്കും. വിവരങ്ങള്‍ മാറ്റാന്‍ Office Profile ല്‍ ക്ലിക്ക് ചെയ്യുക. മറ്റൊരു ബ്രൗസറിലേക്കോ കമ്പ്യൂട്ടറിലേക്കോ മാറ്റാന്‍ Download filled profile ചെയ്ത ഫയല്‍ അവിടെ Upload profile ചെയ്യുക. എല്ലാ ഫീല്‍ഡുകളും അടങ്ങിയ മാതൃക Download sample profile ല്‍ ലഭിക്കും.
    6. RTI പ്രൊഫൈൽ
      വിവരാവകാശ മറുപടികള്‍ക്കായി Settings ലെ RTI Profile ടാബില്‍ Name of S.P.I.O., From Address, Designation, Appellate Authority എന്നിവ മലയാളത്തിലും ഇംഗ്ലീഷിലും പൂരിപ്പിച്ച് Save ചെയ്യുക. ബാക്കി വിവരങ്ങള്‍ Office ടാബില്‍ നിന്ന് എടുക്കും. Appellate Authority എല്ലാ RTI മറുപടികളിലും സ്വയം ചേര്‍ക്കും; Signature ന് മുമ്പോ ശേഷമോ എന്ന് Letter ല്‍ തിരഞ്ഞെടുക്കാം. RTI മറുപടി തയ്യാറാക്കുമ്പോള്‍ Letter കാര്‍ഡിലെ Profile എന്നതില്‍ RTI തിരഞ്ഞെടുത്ത് Letter തുറക്കുക. RTI പ്രൊഫൈൽ Letter ല്‍ മാത്രമേ ബാധകമാകൂ. Browser അടച്ച് വീണ്ടും തുറക്കുമ്പോള്‍ ഇത് Office profile ലേക്ക് തിരികെ മാറും.
    7. Logo ചേർക്കുക
      Header ന്റെ കൂടെ Logo ആവശ്യമെങ്കില്‍ Logo upload ചെയ്യാം. Top അല്ലെങ്കിൽ left position തിരഞ്ഞെടുക്കാം. Profile Setting വഴി ചേര്‍ത്ത ഓഫീസ് വിവരങ്ങളുടെ കൂടെ ഹെഡറില്‍ Logo കൂടി കാണാന്‍ പറ്റും.
    8. Header ചേർക്കുക
      ഈ Application ലെ Default Header, Logo Combination ആവശ്യമില്ലെങ്കില്‍ Full Header Image Option തിരഞ്ഞെടുക്കാം. ഇതിനായി JPG/PNG ഫോര്‍മാറ്റിലുള്ള Full Header Image തയ്യാറാക്കി Upload ചെയ്യുക. Header image തയ്യാറാക്കുമ്പോള്‍ Margin ഇല്ലാതെ ശ്രദ്ധിക്കുക. e-Office ല്‍ draft Save ചെയ്യുമ്പോള്‍ Margine വരും.Windows ല്‍ Screen shot എടുക്കുന്നതിനായി Window key + Shift + S ഉപയാഗിക്കാം.
    9. ഡ്രാഫ്റ്റ് തയ്യാറാക്കുക
      Letter, Proceedings, അല്ലെങ്കിൽ Circular/Notice കാർഡ് തുറക്കുക. ഫോം ഫീൽഡുകൾ പൂരിപ്പിക്കുമ്പോൾ വലതുവശത്ത് Preview തത്സമയം കാണാന്‍ സാധിക്കും. തയ്യാറായ കരട് e-Office ലേക്ക് പകര്‍ത്തുന്നതിനായി ഏറ്റവും അടിയിലുള്ള Copy Draft Button ക്ലിക്ക് ചെയ്ത് e-Office ല്‍ Paste ചെയ്യുക. ഇതേ Draft ഭാവിയില്‍ വീണ്ടും ആവശ്യമാണെങ്കില്‍ Download ചെയ്ത് കമ്പ്യൂട്ടറില്‍ സുക്ഷിക്കാം. ഇതിനായി Download Draft Button ല്‍ ക്ലിക്ക് ചെയ്യാം. വീണ്ടും ആവശ്യം വരുന്ന സമയം മുകള്‍ ഭാഗത്തുള്ള Import Button വഴി Upload ചെയ്ത് edit ചെയ്യാം.
    10. ഡ്രാഫ്റ്റുകൾ Save ചെയ്യുമ്പോള്‍ ഫയൽ നമ്പര്‍/തീയതി അടങ്ങിയ Table ഇടതുവശത്തേക്ക് Align ചെയ്തതായി കാണാം. ഇത് ശരിയാക്കുന്നതിനായി save ചെയ്യുന്നതിനു മുമ്പ് Table - ല്‍ ക്ലിക്ക് ചെയ്തശേഷം Table Properties ല്‍ പോയി Width 100% ആക്കുക.
    11. Copy Options
      മുഴുവൻ കരടും പകർത്തേണ്ടതില്ലാത്ത അവസരങ്ങളിൽ ആവശ്യമുള്ള ഭാഗം മാത്രം തെരഞ്ഞെടുക്കാം. ഇതിനായി Copy Draft — Include Sections ൽ പോകുക.
    12. Print Preview
      Preveiew Panel ല്‍ കാണുന്ന draft ഉം e-Office ലെ Draft ഉം തമ്മില്‍ ചെറിയ വ്യത്യാസങ്ങള്‍ ഉണ്ടായിരിക്കും. കാരണം രണ്ടിലെയും ഫോണ്ടുകൺ വ്യത്യസ്തമാണ്. Preveiew Panel ല്‍ കാണുന്ന draft ന്റെ Printout ആവശ്യമെങ്കില്‍ പ്രിന്റ് എടുക്കാൻ സാധിക്കും
    13. Excel File Upload
      ഈ ആപ്ലിക്കഷനില്‍ Table ചേര്‍ക്കുന്നത് Excel File മുഖേനയാണ്. ഇതിനായി Excel Sheet - ല്‍ ആവശ്യമായി വിവരങ്ങള്‍ ചേ‍ര്‍ത്ത ശേഷം Upload Excel ബട്ടണ്‍ മുഖേന File Upload ചെയ്യുക Letter/Proceedings/Notice Body യില്‍ cursor point ല്‍ Table Insert ചെയ്തതായി Preview-ല്‍ കാണാം. Table Delete ചെയ്യാനും Edit ചെയ്യാനും Split ചെയ്യാനുമുള്ള Options താഴെ നൽകിയിട്ടുണ്ട്.
    14. Manage Address button ഉപയോഗിച്ച് To Address ചേര്‍ക്കാം. ഈ വിവരങ്ങള്‍ Store ചെയ്യുന്നത് ബ്രൗസറിലാണ്.
    15. Upload Data Sheet
      Preview Panel ൽ വലതു വശത്തായി 'Upload Data Sheet' എന്ന ബട്ടണ്‍ കാണാം. ഇത് വഴി Excel File/csv Upload ചെയ്യാം. ഇവിടെ Upload ചെയ്ത Excel Sheet ലെ മുഴുവൻ Tab കളും ഇവിടെ കാണാം. ഈ Data ഒരു ക്ലിക്കിലൂടെ cursor point ലേക്ക് Copy Past ചെയ്യാം. കൂടാതെ Excel Sheet ലെ വിവരങ്ങൾ Search ചെയ്യാനും സാധിക്കും. കരടുകൾ തയ്യാറാക്കുനനതിന് സ്ഥിരമായി ഉപയോഗിക്കുന്ന വാക്കുകൾ/വാചകങ്ങൾ excel sheet ൽ തയ്യാറാക്കി Upload ചെയ്താൽ എളുപ്പത്തിൽ Copy Paste സാധിക്കും.
    16. Mail Merge
      Template ഉപയോഗിച്ച് ഡ്രാഫ്റ്റുകൾ തയ്യാറാക്കാൻ ഈ Mail Merge ഉപയോഗിക്കാം. ഇതിനായി ആദ്യം Template തയ്യാറാക്കുക. Template ല്‍ പൂരിപ്പിക്കാനാവശ്യമായ വിവരങ്ങള്‍ Excel Sheet ൽ തയ്യാറാക്കുക. Google Sheet ൽ തയ്യാറാക്കുന്നതാണ് നല്ലത്. ശേഷം excel/CSV ഫയൽ Download ചെയ്യുക. ഈ ഫയൽ അപ്‌ലോഡ് ചെയ്യുക. ഓരോ കോളം ഹെ‍ഡറിനു മുകളിലും {} നുള്ളില്‍ Placeholder കാണാം. ഇതില്‍ ക്ലിക്ക് ചെയ്ത് കോപ്പി ചെയ്ത് Template ല്‍ ആവശ്യാമായ സ്ഥലങ്ങളിൽ Paste ചെയ്യുക. ശേഷം Next Button ക്ലിക്ക് ചെയ്യുക. അപ്പോള്‍ Placeholder ന്റെ സ്ഥലത്ത് യഥാ‍ര്‍ത്ഥ Table value വരുന്നതായി കാണാം. ഇപ്രകാരം ഓരോ excel/csv വരികളിലേയും data Template ലേക്ക് വരുന്നതിനായി Next Button Click ചെയ്യുക. ഓരോ ഡ്രാഫ്റ്റും Copy ചെയ്ത് e-Office ല്‍ പേസ്റ്റ് ചെയ്യുക.
    17. Mail Merge ലെ മുഴുവന്‍ കരടുകളും ഒരുമിച്ച് PDF ആയി കാണാന്‍ 📄 All Drafts ബട്ടണിൽ click ചെയ്യുക
